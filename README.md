# ToraNeko.Mk3

ToraNeko (Mk3) のソフトウェア・ハードウェア（回路）・機構設計をまとめて管理するリポジトリです。
前身の KOGUMA.Mk3 系リポジトリはソフトウェアのみを対象としていましたが、本リポジトリでは
回路図・基板データ・配線資料なども含めて一元管理し、ソフトとハードの変更履歴を紐付けて追跡できるようにします。

## ディレクトリ構成

```
.
├── software/    # マイコン・PC側ソフトウェア一式
├── hardware/    # 回路図・基板データ（KiCadプロジェクト）・BOM
├── mechanical/  # 機構部品・3Dモデル・図面
└── docs/        # 配線図、仕様書、設計メモ、議事録などのドキュメント
```

各ディレクトリの詳細は、それぞれの README.md を参照してください。

## 設計データの管理方針

- 回路・基板設計は [KiCad](https://www.kicad.org/) を使用します。プロジェクト一式は `hardware/kicad/` 以下にサブシステムごとのディレクトリを作って格納します。
- ソフトウェアは `software/` 以下にサブシステム・マイコンボードごとのディレクトリを作って格納します。
- 既存の KOGUMA.Mk3 のソフトウェア資産は、必要になったタイミングで個別に移行するかを検討します（現時点では未移行）。
