# mechanical/

機構部品・筐体・3Dモデル・図面など、機械設計に関するデータを格納します。

## 構成の考え方

パーツ・アセンブリ単位、もしくはサブシステム単位でディレクトリを分けて配置してください。例:

```
mechanical/
├── frame/         # 車体・フレーム
├── drive-unit/    # 駆動系機構
└── exported/      # 発注・共有用に書き出したSTEP/STL等
```

## 補助パーツ（FDM 印刷）

機体に取り付ける補助パーツと、製作・調整用の治具です。どれも CadQuery の生成スクリプトと、印刷用の STL、Fusion 360 で機体に重ねて確認できる STEP（機体の STEP と同じ座標）を置いています。

| ディレクトリ | 内容 |
|---|---|
| [skirt_slider/](./skirt_slider/) | 吸引ファン用スカート枠（前後のスライダー付き、両面テープで貼る。長方形の版もある）と、スカートなしで使う前後のスライダー |
| [battery_holder/](./battery_holder/) | バッテリー 2 本を上部固定基板の上に固定するホルダー |
| [case_insert/](./case_insert/) | ケース（お弁当箱）の中子に入れて、機体を動かないように納める受け台。中子の寸法は写真からの推定値 |
| [jigs/maintenance_stand/](./jigs/maintenance_stand/) | 機体を載せるとタイヤが浮くメンテナンス用スタンド |
| [jigs/centering_plate/](./jigs/centering_plate/) | 機体を区画の決まった位置に置くセンタリング板。まっすぐ版（区画の中心）と斜め版（辺の中点に 45°、左右）と境目版（車軸を区画の境目に。会場ごとの倍率合わせ用）。位置決めに要るところだけの細い枠で、置いたままスタートできる |
| [jigs/encoder_solder_jig/](./jigs/encoder_solder_jig/) | エンコーダ基板はんだ付け治具。メイン基板の縁（タイヤ用の切り欠き）を挟んで留める（ネジ不要） |

## 迷路の部品

| ディレクトリ | 内容 |
|---|---|
| [maze/](./maze/) | 位置を変えられる壁を作るための壁の STEP（`MicroMouseRefWall_1.step`。86.1 × 25 × 6mm）。2 個を向かい合わせに立てると、その溝（5mm おき）に別の壁を差して、壁の位置を 5mm 刻みで変えられる |

CADツールは **Fusion 360** を使用しています。
