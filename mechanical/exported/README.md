# mechanical/exported/

Fusion 360 から書き出した共有用データ（STEP等）を置いています。

## TORANEKO.Mk3_v36.step

機体全体のアセンブリ（Fusion 360 のトップコンポーネント「全体」v36、単位mm）。

主な構成部品:

| 区分 | 部品 |
|---|---|
| 基板 | 基板（メイン基板）、上部固定基板、エンコーダ基板 × 2 |
| 駆動系 | NFP-D0812 モータ × 2、モータマウント × 2、ピニオンギア m0.3 11T × 2、平歯車 m0.3 41T × 2（減速比 41/11 ≒ 3.73）、ベアリング LF-630 × 4、3×6 平行ピン × 2 |
| 足回り | ホイール × 2、ミニッツタイヤ × 2 |
| エンコーダ | 3mm 磁石 × 2（エンコーダ基板上の AS5047P で検出） |
| 壁センサ | センサホルダ × 4、3mm 砲丸LED × 4 |
| 吸引 | 吸引ファン Φ30（アクリル）、吸引ファンモータマウント |
| 電源 | ヤシの木バッテリー 100mAh × 2 |
| その他 | 支柱 |

基板外形のDXFは `hardware/kicad/TORANEKO.Mk3/` にあります。
