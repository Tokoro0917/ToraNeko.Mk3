### 第2が終わってから: 探索の直進に壁切れの距離補正(2026-10-13 相談)

探索の直進(境目から次の境目まで180mm)で、柱の端から次の境目を推定して、残りの距離を直す。第2で柱の壁切れが完璧になってから取りかかる。間に合わなければ大会のあと。

- 流れ: 4割ほど進む → 柱の端を探す → 見つけたら、次の境目の推定(`Edge_Cut_Find`、`Edge_Off`)に合わせて残りの距離を直す。速度は変えない
- 端が見えるのは直進のほぼ半分(境目から約96mm)。横センサは区画中心で柱の真ん中を見る向きなので、走るあいだに今の区画の壁の後ろ半分 → 次の境目の柱 → 次の区画の壁の前半分を見る
- 片側ごとに見えるもの(今の区画 → 次の区画):
  - 壁あり → 壁なし: 壁の終わり(下がる端)。今の検出で補正できる
  - 壁なし → 壁なし: 柱だけ(下がる端)。今の検出で補正できる
  - 壁なし → 壁あり: 上がる端だけ。今は補正できない(上がる端の検出とオフセットを足せばできる。後回しでよい)
  - 壁あり → 壁あり: 何も変わらない。補正できない
  - 左右どちらかで見つかれば補正、両方なら平均(最短の柱の壁切れと同じ)
- **両側とも「壁あり → 壁あり」のときは補正しない**(距離のまま進む)。横に曲がる区画は曲がる側に壁がないので、その区画に入る直前の直進では、曲がる側に必ず下がる端(壁の終わりか柱だけ)が見える。つまりターンの直前は必ず補正できる。長い通路ではずれても壁を見るタイミングが数mm変わるだけで、通路の出口(横が開く)で補正される。行き止まりは今までどおり前壁で合わせる。壁と柱の継ぎ目や遠くの前壁を読む方法は不安定なので使わない
- 誤検出を防ぐ: 見つける範囲を「予想した境目 ± 20mm」(`Edge_Win`と同じ)に限り、1回に直す量にも上限を付ける(例 ±15mm)
- 探索の速度(500・1000)の`Edge_Off`は、モード3 No.6・No.7で測った値をそのまま使う
- 探索中も壁切れのログを取り、ビューアで直した量を見られるようにする
- ターンのあとの後距離など、境目から境目までの直進以外は対象にしない
