# 壁制御と壁切れ: ほかの人のやり方(2026-10-11調べ)

九州地区大会(10-25)に向けた「第1: 壁制御の安定化」「第2: 壁切れを完璧にする」のために、ほかの人のやり方を調べて、KOGUMAの今のやり方と比べた。

調べたもの: 公開されているコード(KERISE〈kerikun11〉、UKMARS mazerunner-core)、日本のブログ(carmine、ぱわぷろ、RT、tenpura、なおフィス、tokor)、micromouseonline(Peter Harrison)。

## 壁制御

### ほかの人のやり方

| やり方 | 誰が | KOGUMA |
|---|---|---|
| 誤差のPD制御。Pだけだと原理的に振動が残るので、D(または角度)が要る | tokor(制御理論の解析) | PDでやっている |
| **低速では壁制御を切る** | ぱわぷろ(重心速度が一定以下でカット)、KERISE(240mm/s未満は補正しない)、UKMARS(速度0からは制御しない) | ゲインが速度/500倍なので、低速ではほぼ効かない(`WallCtrl_mm_GainMin` = 0) |
| **壁が消えかけているときは、吸い込まれる向きの制御量を0にする** | carmine(変化量が閾値以上なら、吸い込まれる向きを0) | 距離が10mm進む間に15mm以上変わった壁は使わない(`WallCtrl_mm_StableTH`)。考え方は同じ |
| 出力に上限を付ける | UKMARS(`STEERING_ADJUST_LIMIT`) | 誤差を片側±20mmで頭打ち |
| 前壁が近いときは横壁制御を切る(横センサが前壁や柱を見るため) | UKMARS(`FRONT_WALL_RELIABILITY_LIMIT`) | 前センサが800を超えたら切っている |
| **両側に壁があるとき、近いほうの壁だけを使う**(誤差を2倍) | UKMARS | 左右の差(`Err_L - Err_R`)を使っている |
| **壁に寄りすぎたときだけ押し返す**(中心付近では何もしない) | KERISE(壁までの距離が基準より近いときだけ、推定位置を5%ずつ直す) | 中心でもいつも効いている |
| 機体の向きがまっすぐのとき(0.5°以内)だけ補正する | KERISE | 向きは見ていない |
| 横壁制御の結果をモーターに直接足さず、推定位置を直してから位置の制御で追わせる | KERISE | モーターの出力とジャイロの目標に直接足している |
| センサの向きは、区画中心に置いたときに柱を見る角度。角度が大きいと壁の読み違い、小さいと飽和 | RT(槇原研修) | ハードの話。今は変えない |

### 調整の仕方(tenpura、フレッシュマン向け)

- 迷路に線を引いて、ずれが見えるようにする(下板が黒いので、白い鉛筆か修正液)
- **片壁ずつ**(左だけ・右だけ)制御をかけて、リファレンス値が合っているかを見る
- 目安は、**1区画くらいで中心に戻る**こと。震えながら走るのはだめ
- 壁から離れる向きと近づく向きの両方を試す
- 大会会場では片壁制御のチェックだけにして、壁切れの調整は事前に済ませておく

### KOGUMAで試すこと(簡単な順)

1. **片壁ずつの確認**。左だけ・右だけの通路で、ずらして置いて1区画で戻るか。左右で戻り方が違えば、センサの倍率か、そちら側のセンサの問題
2. **使う/使わないの切り替えにヒステリシスを付ける**。今は120mmの1本の線で切り替えていて、2026-10-10に「中心から20mmずれると切り替わり続けて戻れない」ことがあった。例えば120mmを超えたら使わない、110mmまで近づいたらまた使う
3. **両側に壁があるとき、近いほうだけを使う**(UKMARS)。遠いほうの壁はセンサの分解能が悪く、ノイズの多い左センサの影響も減る。試すならフラグで切り替えられるようにする
4. **中心付近に不感帯を付ける**(KERISE)。例えば±1〜2mmは0にする。中心付近の細かい揺れ(D項がセンサのばらつきを拾う)が減る
5. **D項を数msの差で取る**。今は1msの差なので、センサのばらつきをそのまま拾う。3〜5ms前との差にして、そのぶんKdを割る

推定位置を直す方式(KERISE)は作り直しが大きいので、2週間ではやらない。

## 壁切れ

### ほかの人のやり方

| やり方 | 誰が | KOGUMA |
|---|---|---|
| 横センサが閾値を下回ったところを壁の終わりにする | ほぼ全員 | `Cut_L`/`Cut_R` = 80 |
| **閾値を、その区間で見た最大値の半分にする**(会場の明るさに左右されにくい) | UKMARS(`conf_edge_detection`) | 決まった値(80)。会場で変わる |
| **センサ値と変化量の両方で判定する**。基本はセンサ値で、姿勢が乱れたときの誤判定を変化量で防ぐ | carmine(全部のターンで壁切れを確認してからターン) | 壁ありはセンサ値だけ。柱版は変化量だけ |
| 柱を、センサ値の変化の大きさ(フィルタした傾き)で見つける | micromouseonline | 柱版で、5mm進む間に40以上減ったら(`Pillar_Edge()`) |
| 柱のところで、壁切れが0回・1回・2回と出ることがあった | micromouseonline | 1回反応したら終わりにしているはず。ログで確認する |
| **加速中と減速中で、壁切れの位置がずれる**(タイヤの滑り)。4m/s近くでは、加速中の区画が約200mm、減速中が約160〜173mmに見えた | micromouseonline | 速度ごとの違いは見ていない |
| 前壁があるときは、前壁の距離でターンを始める。壁切れより前壁を優先する | UKMARS(前センサの和でターン開始)、KERISE(前壁で位置を直す) | 探索では前壁、最短では壁切れだけ(確認する) |
| 壁切れの補正は使わず、前壁と横壁で位置を直す | KERISE(`MOVE_ACTION_WALL_CUT_ENABLED` = 0) | — |
| 左右で壁切れの位置が違えば、その差から横のずれ(向きのずれ)がわかる | micromouseonline | 使っていない |
| 斜めは、壁切れからの距離ごとに「理想のセンサ値」の表を作り、それとの差で制御する。柱の近くの不安定な区間では使わない | なおフィス | 斜めは決まった閾値(150)と、110を超えたら押し返すだけ |
| 壁切れを使う前に、壁の消える数十ms分のセンサ値を残しておく | ぱわぷろ | 1msごとに10個残している |

### KOGUMAで試すこと(簡単な順)

1. **壁切れした位置をログに出す**(どの方法で反応したかも)。UKMARSにも、まっすぐ走って壁切れの位置を出すだけのテストモードがある。同じものを作る(例: 後ろの壁に付けて置き、4区画を一定速度で走り、左右の壁切れの位置を出す)
2. **速度ごと・加速中/減速中で、壁切れの位置がどれだけずれるかを測る**。ずれが大きければ、前距離・後距離を速度ごとに持つ
3. **閾値を「その区間で見た最大値の割合」にする**(UKMARS)。会場の明るさが変わっても、壁切れの位置が変わりにくい。今の`Cut_L`/`Cut_R`(80)と並べて、ログで位置を比べてから決める
4. **壁ありの壁切れにも変化量の条件を足す**(carmine)。センサ値が閾値を下回り、かつ減っているときだけ反応させ、姿勢が乱れて一瞬下がったときの誤反応を防ぐ
5. **前壁があるターンは、前壁の距離で前距離を合わせる**(最短で、ターンの先に前壁があるとき)。今の最短で前壁を使っているか確認する
