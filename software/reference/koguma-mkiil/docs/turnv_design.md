# ターンごとの通過速度(`Short_NANAME_MoveTurnV`、モード1 No.10・No.11)

README から移した(2026-10-12)。調べたことは`turn_speed_research.md`。単体のテストはモード10。

2400は一番きついターン(V90)に合わせた速度なので、横加速度に余裕のあるターンは速く、きついターンは遅く回る。`Short_NANAME_Move2400`と同じ走り方で、ターンの種類ごとに通過速度を持つ(2026-10-07に2000基準から2400基準に作り直した。調べたことは`turn_speed_research.md`)。

- 速度は`Move.c`の`TurnV_Table`の`v`で設定する。左右は同じ値を使う。**`v`を全部2400にすると`Short_NANAME_Move2400`と同じ走りになる。**
- 旋回のパラメータ(角度・角速度・角加速度・前距離・後距離)は`Short_NANAME_Move2400`の値を基準にして、通過速度Vに合わせて角速度を V/2400 倍、角加速度を (V/2400)² 倍にする。理想的には同じ軌跡(同じ旋回半径)で、横加速度が (V/2400)² 倍になる。前後のオフセット距離は理想的には変わらないが、実機では滑りや遅れで変わるので、速度を変えたターンは`offset_st`/`offset_end`を調整する(モード10 No.1〜7)。
- 走り出しは`Short_NANAME_Move2400`と同じ(最初が直線ならスタート区画の境目までに加速、最初がターンなら`G_First_Turn`のターンごとの速度で曲がって後距離で加速)。ゴール停止区間の入口は2400が上限。斜めの直線の加速度は`AC - 10000`(2400と同じ)。

速度のつなぎ方(`Core/Src/SpeedPlan.c`):

- **間に直線があるとき**: 後距離はそのターンの速度で一定に走り、直線で次のターンの速度に合わせる。直線が短くて加減速しきれなければ、その範囲までターンの速度を下げる(motor.cのcos加減速の距離の式で、直線の9割で収まるようにする)。
- **ターンが直線を挟まずにつながるとき**: 前のターンの後距離のうちに、次のターンの速度へ加速度30000(`TURNV_AC_BACK`)で変える。後距離が壁切れで早く終わることがあるので、後距離の8割(`SPEEDPLAN_BACK_MARGIN`)で変えきる。次のターンの前距離は、そのターンの速度で一定に走る。変えきれないときは、変えきれる速度まで速い方のターンを下げる(遅い方にそろえることはしない)。
- 後距離で速度を変えるのは`Motor_Wallcut_END_Accel`/`Motor_Wallcut_END_NANAME_Accel`(最初のターン用に作ったもの。減速もできるようにした)。

速度の初期値と考え方。`Short_NANAME_Move2400`のパラメータで見積もったピーク横加速度(速度2400、角速度が三角形になる場合の頭打ちを考慮)が一番大きいのはV90。**V90の限界を2200とすると**、限界の横加速度は約91.5m/s²(9.3G)で、ほかのターンがそこに届く速度は次のとおり。

| ターン | 2400での横加速度[m/s²] | 限界に届く速度 | 初期値(`TurnV_Table`) |
|---|---|---|---|
| V90 | 109 | 2200(基準) | 2200 |
| 斜め入り45 | 90 | 約2420 | 2400 |
| 斜め出135 | 88 | 約2450 | 2400 |
| 斜め入り135 | 84 | 約2510 | 2400 |
| 大回り90 | 67 | 約2800 | 2600 |
| 大回り180 | 63 | 約2900 | 2500 |
| 斜め出45 | 59 | 約2980 | 2600 |

- 伸ばせるのは大回り90・大回り180・斜め出45。2700(`Short_NANAME_Move2700`)の大回り90は約94m/s²、V90は約132m/s²で、限界を超えている(2700で走れなかったことと合う)。
- 大回り180はほかの人も遅めにしているので、初期値を特に控えめにした。
- 斜め出45は後距離が40mmしかないので、上げすぎると斜め入りに続く場所で下げられる(2980→2420は加速度30000では変えきれない)。
- この見積もりは「限界は横G(滑り)で決まる」という仮定に立っている。V90が怪しい原因が柱や壁の補正なら、V90を基準にした表は当てはまらない。

ランダム迷路1000個(ダイクストラ、ループ30本)の経路で、初期値のときにターンが表の速度のまま回れる割合は 大回り90 91%、大回り180 94%、斜め出45 83%、ほかは100%。2400未満に下がるターンはない(V90は表で2200)。
