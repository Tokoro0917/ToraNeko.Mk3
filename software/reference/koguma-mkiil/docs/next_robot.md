# 新機体に向けて: 今の機体(KOGUMA MkIIl)のよくない点(2026-10-21)

今の機体のログ(2026-10-18〜20)とコードから、新しい機体を設計するときに直したい点を、効く順に並べた。数字の出どころは `docs/noise_limits.md` と `tools/limits.py`。ソフトだけで直せるものは最後にまとめた(新機体でも同じことが起きないよう、最初から作りに入れる)。

## まとめ

| 順 | よくない点 | 根拠(今の機体) | 新機体でどうするか |
|---|---|---|---|
| 1 | **電源の内部抵抗が大きい** | 電池+配線で約0.64Ω。最短で約5A流れ、15.8V → 12.4〜12.8V に落ちる(約2割) | 電池・コネクタ・配線・スイッチを低抵抗に。全部で 0.2〜0.3Ω を目標 |
| 2 | **モーターの電圧が足りない(ターンの立ち上がり・速い直線)** | 2000 の斜め入り45・V90 で毎回 30〜50ms 張り付き。直線の加速 20000 は 2m/s より上で上限を超える | 1 を直したうえで、モーター(Kt/√R の大きいもの)とギア比を選び直す |
| 3 | **モーターの定数が分かっていない** | `KT` 2.63 mNm/A と `KE` 0.00209 V/rpm(= 20 mNm/A 相当)が約7.6倍食い違う。FF は `Aff` 0.65・`Bff` 0.50 の手合わせで埋めている | 型番と定数を資料に残す。電流を測れるようにして、実測で定数を決める |
| 4 | **電流・左右の車輪の速度が分からない** | ログは平均の速度 `v` と電圧だけ。滑り・電流・張り付きの原因を分けられない | モータードライバの電流検出をADCに入れる。左右の車輪の速度をログに出す |
| 5 | **センサの一部(FL・L)に吸引・車輪のPWMのノイズがのる** | 止まって吸引を回すと FL・L だけ標準偏差 2〜3 → 6〜16(PWMに合わせて読んで 2.6〜4 に)。走ると L だけ今も右の5〜10倍、ときどき跳ねる | センサのアナログとGNDを、モーター・吸引の電流の通り道から離す。ADC の読むタイミングをタイマーで決める |
| 6 | **センサの左右の感度がそろっていない** | 横37mm で L 910・R 780、境目の前壁(約174mm)で 1mm あたり FL 1.2・FR 2.2 | 発光・受光の向きと距離をそろえる治具。遠くの前壁の分解能を上げる |
| 7 | **滑ったぶんだけ距離がずれる** | 最短で、柱の推定がエンコーダの距離より 13〜38mm 先。吸引なしの 500 では発進で約37mm | タイヤ・吸引の見直し。加速度センサとエンコーダを組み合わせる前提で IMU を置く |
| 8 | **RAM が足りない** | 16×16 で約115KB / 128KB。32×32 は入らない。会場ごとの値をフラッシュに保存していない | RAM の多いマイコンにする。設定を保存する場所を最初から決める |

## 1. 電源の内部抵抗

- 内部抵抗(電池の電圧の落ち方を電流で割ったもの、配線込み)は **0.56〜0.79Ω、中央値0.64Ω**(電流が 3A を超えるログ18本、R² 0.91〜0.95)
- 最短走行のピーク電流は 4.5〜5.2A(左右のモーター + 吸引 約0.5A)。そのとき約3.3V 落ちる
- 4セルで1セル 0.16Ω にあたる。小さいリポでも新しければ1セル 0.05〜0.1Ω くらいなので、電池が古いか、コネクタ・配線・スイッチ・逆接続防止の部品などに抵抗があると思われる。**どこで落ちているかは今の機体で測っておく**(下の「設計の前に測っておくもの」)
- 効き目: 0.3Ω にできれば、張り付くときの電池が約1.5〜1.7V 上がる。直線の加速の上限が 2m/s で +4.8m/s²、ターンの立ち上がりの角加速度の上限が +約1.5万deg/s²(`docs/noise_limits.md` の「3. 限界」)
- 新機体では: 電池の端子から基板までを太く短く、コネクタは定格に余裕のあるもの、電源スイッチを大電流の経路に入れない(FET で切る)、電池の電圧を測る点を電池の近くに置く(今はどこで測っているか分からない)。電源にコンデンサを足しても、数十ms続くターンの立ち上がりの落ち込みはあまり減らない(電池の抵抗そのものを下げる)

## 2. モーターとギア比

今の機体: ギア比 1.7073、タイヤ径 23.42mm(10-21 に 23.1 から測り直した。この資料の数字は 23.1 のときのログで、速度・距離は約1.4% 小さく出ている)、トレッド 55mm、重さ 78g(`Define.h`)。モーターの巻線抵抗 5.4Ω。

- 1輪の電圧のモデル(`docs/noise_limits.md` の「2」): 並進 V = 1.25 + 1.5v + 0.35a、回転 ΔV = 0.063ω + 0.006ω̇
- ターンの立ち上がり(ωが小さいうち)で使える角加速度は、今の電池で **約7.5〜8.5万deg/s²**。2000 の斜め入り45(11.5万)・V90(12.3万)、2400 の V90(14.4万)はこれを超えていて、張り付いたまま曲がっている。横Gは 2000 で 64〜70m/s²、2400 で 75〜91m/s² まで出ているので、**滑る前に電圧が足りなくなっている**
- 回転のしにくさ(慣性モーメント)は、回転と並進の係数の比から約3.7×10⁻⁵ kg·m²(回転半径 約22mm)。重さが真ん中に寄っていて、ここは悪くない。新機体でも重いもの(電池・モーター)を真ん中に寄せる
- ギア比だけを変えたときの見積もり(今のモーター、電池 13.1V、FBに1V残す。速度に比例する損失もモーターの回転数に比例するとした):

| ギア比 | 最高速 | 加速の上限 1m/s | 2m/s | 3m/s | 4m/s | 角加速度の上限(2m/s) |
|---|---|---|---|---|---|---|
| 1.71(今) | 7.2m/s | 26.7 | 22.4 | 18.1 | 13.9 | 7.5万 |
| 2.0 | 6.2m/s | 30.4 | 24.6 | 18.7 | 12.8 | 8.2万 |
| 2.4 | 5.1m/s | 35.1 | 26.6 | 18.2 | 9.7 | 8.9万 |
| 3.0 | 4.1m/s | 41.2 | 28.0 | 14.8 | 1.5 | 9.4万 |

(加速の単位は m/s²)

- 今の最短の最高速は 4.6m/s くらいまで、6000 に届くのは14区画以上の直線だけ。ギア比を 2.0 くらいに上げると、立ち上がりの角加速度と低い速度の加速が1割ほど上がり、最高速は 6m/s を残せる。ただし**ギア比で取れるのは1〜2割**。11〜12万deg/s² のターンを張り付かずに曲がるには、電源(1)とモーターそのものを良くする必要がある
- モーターは「同じ大きさでどれだけ力が出るか」(Kt/√R)で比べる。今は Kt の値自体があやしい(3)ので、比べる前に今のモーターの定数を実測する

## 3. モーターの定数

- `Define.h` の `KT` = 0.00263 Nm/A と `KE` = 0.00209 V/rpm は、単位をそろえると Kt = Ke になるはずなのに約7.6倍違う(KE は 0.020 V/(rad/s) = 20 mNm/A 相当)
- FF は `Aff` = 0.65、`Bff` = 0.50 を掛けて合わせてある。ログから求めた速度の係数(1.5 V/(m/s))は `Bff`×`KE` の 1.47 とよく合うが、これには逆起電力のほかにギアと吸引の損失が混ざっている。KT から出した逆起電力は 0.39 V/(m/s) しかない
- どちらが正しいかで、電池の電流の見積もり(内部抵抗)も変わる(今は KT から出した逆起電力で計算した)
- 新機体では: モーターの型番とデータシートの値を資料に残す。電流を測って(4)、止めたとき(巻線抵抗)と空回し(逆起電力)の2つの試験で実測する

## 4. 測れないもの

- 今の走行ログには、平均の速度 `v`・ジャイロの角速度・左右のモーターの電圧(指令)・電池の電圧しかない
  - 左右の車輪の速度がないので、ジャイロと比べた**滑り**が分からない。2400 の V90 が曲がれないのが電圧のせいか滑りのせいかを、電圧のモデルからしか言えない
  - 電流がないので、モーターの定数(3)と電池の内部抵抗を、モデルを通してしか出せない
- 新機体では: モータードライバの電流検出(またはシャント抵抗)を ADC に入れる。左右の車輪の速度・電流・電池の電圧を1msでログに残す。走行ログは RAM が足りなくなりやすいので、ログ用の RAM(8)も見込む

## 5. センサにのるノイズ

`docs/sensor_noise.md`、`docs/noise_limits.md` の「1」。

- 吸引の PWM の電流が **FL(ADC ch13、PC3)と L(ch11、PC1)だけ**にのる。止まって標準偏差 FL 2.8 → 14〜16、L 1.8 → 6〜7。点灯時と消灯時に同じだけのるので、LED ではなく電気(GND の戻り道か配線)と考えている。R・FR はほとんど変わらない
- 車輪の PWM(TIM3、50kHz)も L にのる。読むタイミングを PWM に合わせて、走ったときの L の標準偏差 73 → 10〜20 にしたが、まだ右(約2)の5〜10倍で、ときどき跳ねる
- ソフトで合わせて読むために、1ms に3回、最大 20us ずつ割り込みの中で待っている
- 新機体では:
  - センサの受光のアナログ線と GND を、モーター・吸引の電流の通り道から離す(GND を1点でつなぐ、吸引のモーターの近くに電源のコンデンサ)。ADC の入力に RC を付ける
  - ADC をタイマーのトリガで始め、PWM の決まった位置で点灯時・消灯時を読む(ソフトで待たない)。今は LED が2組(FL・R と L・FR)で、点灯時と消灯時を十数us ずらして読んでいる
  - 取り込み時間は今 3 サイクル(0.27us)。受光の出力の抵抗が高いならバッファを入れる

## 6. センサの感度と向き

- 同じ距離で左右の値が違う: 横 37mm で L 910・R 780、区画中心で L 約240・R 約200。前の境目(前壁まで約174mm)の 1mm あたりの変化が FL 1.2・FR 2.2 で、FL は遠くの分解能が半分
- 会場ごとの倍率 `WallDist_Scale`(0.96〜1.02)と左右別の表で合わせている。合わせられるが、向きのずれは壁切れの位置(`Edge_Off` が左右・種類ごとに 87〜99mm)にも出ている
- 前センサの表は 60mm より近い点がない(今の機体では測っていない)
- 新機体では: センサの向きを決める治具(またはセンサの位置決めの穴)を作る。前センサは、境目で前壁を見るとき(約170mm)の 1mm あたりの変化が大きくなる向き・発光の強さにする

## 7. 滑りと距離

- 最短走行で、柱から推定した境目がエンコーダの距離より 13〜38mm 先にあった(`docs/pillar_cut_design.md` の「12」)。距離が本当より先に進んでいる = 発進・加速で滑っている
- 吸引なしの 500mm/s では、発進で約37mm ずれた
- ジャイロは吸引を回すと止まっていても 4〜8 dps 揺れる(振動)。吸引の前にゼロ点を測る作りにしている
- 新機体では: タイヤの材質と幅、吸引の強さを、最初の試作で滑りを測って決める。IMU は機体の中心の近く、吸引のモーターの振動が伝わりにくいところに固く付ける。加速度センサとエンコーダを組み合わせて速度を出せるよう、IMU の加速度も 1ms で読める配線にする

## 8. マイコンと RAM

- STM32F446RE(RAM 128KB)。16×16 で約115KB 使っている(うち走行ログ 2000行で約68KB)。32×32 は入らない
- 会場ごとの倍率をフラッシュに保存していない(毎回書き写してビルドし直す)
- 新機体では: RAM の多いマイコン(256KB 以上)か、ログ用の外付けメモリ。フラッシュに設定を保存する場所を最初から決める

## ソフトで直せるもの(新機体でも最初から入れる)

今の機体でも直せるが、新機体では最初からこの形で作る。

- **距離を、平均する前のエンコーダの値で積む**。今の `G_Odo_X`・`G_Motor_X` は20回平均した速度を積んでいて、速度 × 約9.5ms 遅れる(2000mm/s で約19mm)。壁切れの「速いほど手前に出る」(`Edge_V_K`)の有力な原因。速度のFBの平均も短くする
- **FF を今の電池の電圧で計算する**(`Run_Voltage` は走る前の値のまま)
- **ターンは電圧の上限の中で作る**。ターンを作るときに、`tools/limits.py` の「4」と同じ計算で必要な電圧を出し、電池 − 1V を超えないことを確かめる
- ジャイロ・エンコーダはまとめて読む(上位・下位を別々に読むと値が混ざる。10-20 に直した)
- フェイルセーフ(`docs/search_stability_research.md`)

## 設計の前に、今の機体で測っておくもの

1. **電圧がどこで落ちているか**: 最短か、加速の強い直進を走らせながら、電池の端子・電源スイッチのあと・モータードライバの電源の3点の電圧を同時に測る(オシロか、テスターの最低値)。電池だけ替えて同じ試験もする
2. **モーターの定数**: 車輪を浮かせて一定の電圧で空回しし、エンコーダの回転数から逆起電力(Ke)を出す。巻線抵抗はテスターで。KT と KE の食い違い(3)を決着させる
3. **左右の車輪の速度**をログに出して、2400 の V90 で滑っているかを見る(今の機体でソフトだけでできる)
4. **電池を減らした状態**(走る前 15.5V くらい)で 2000 の最短を1回。電圧で曲がり方がどれだけ変わるか
