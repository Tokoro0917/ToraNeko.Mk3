# 次の機体の電源メモ：TPS55289 で昇圧する案

ToraNeko.Mk3 では**使わない**。次の機体で検討するためのメモ（2026年の相談内容のまとめ）。

- 対象 IC：TI **TPS55289**（4スイッチの昇降圧コンバータ、I2C で出力電圧を設定できる）
- 検討している使い方：**2セル LiPo を約2倍（15V前後）に昇圧**して、モータドライバに給電する
- 数値の出典：[TPS55289 データシート (SLVSGA9A)](https://www.ti.com/lit/ds/symlink/tps55289.pdf)、[製品ページ](https://www.ti.com/product/TPS55289)

## 2S → 15V に昇圧したときに取れる出力電流

昇圧動作では、インダクタの平均電流がそのまま入力電流になる。

```
最大出力電流 ≈ 平均インダクタ電流の上限 × (入力電圧 ÷ 出力電圧) × 効率
```

効率 95% として計算した値：

| 電池電圧 | typ 8A のとき | min 6.7A のとき |
|---|---|---|
| 8.4V（満充電） | 約4.3A | 約3.6A |
| 7.4V（公称） | 約3.8A | 約3.1A |
| 6.0V（放電末期） | 約3.0A | **約2.5A** |

- 設計は**放電末期・min 値の約2.5A**で考える。
- 出力電圧を 12V に下げれば、放電末期・min 値でも約3.2A 取れる。電圧を下げるほど電流に余裕が出る。
- 電池から流れる電流は、出力電流の2倍強になる（例：15V・2A を 6.0V から出すと、入力は約5.6A）。電池・コネクタ・配線はこの電流に耐えるものを選ぶ。

## 出力電流をアナログで見る方法（CDC ピン）

出力ラインの ISP–ISN 間に検出抵抗 Rsense を入れると、CDC ピン（16番）に電流に比例した電圧が出る。これを STM32 の ADC で読む。

```
V_CDC = 20 × (V_ISP − V_ISN) = 20 × Rsense × I_OUT
```

Rsense = 10mΩ のとき：

| 出力電流 | 検出電圧 | CDC 電圧 |
|---|---|---|
| 0.5A | 5mV | 0.1V |
| 1A | 10mV | 0.2V |
| 3A | 30mV | 0.6V |
| 5A | 50mV | 1.0V |

- 抵抗での損失は 3A で約90mW。
- ADC の分解能を活かしたいなら 20mΩ（3A で 1.2V）。そのときは電流制限の上限が約3.2A になる。
- I2C で電流値を読むレジスタは**無い**。STATUS レジスタ（07h）で分かるのは短絡・過電流・過電圧のフラグだけ。

注意点：

1. **小電流は精度が悪い**。検出電圧 50mV で CDC は 0.93〜1.05V（±5%）だが、2mV では typ 40mV・max 75mV とオフセットが大きい。10mΩ だと 0.5A 以下はあまり当てにならない。
2. **出力電圧は内部帰還（I2C 設定）で使う**。外部の抵抗分圧で出力電圧を決めると、CDC ピンの電流で出力電圧が持ち上がる仕組み（ケーブルの電圧降下の補正）になっている。内部帰還にして、レジスタ 05h の CDC[2:0] をデフォルトの 000（補正 0V）のままにすれば、電流モニタとしてだけ使える。
3. 見えるのは**モータ2個（とつないだものすべて）の合計電流**。左右の個別の電流は分からない。
4. CDC 出力の応答速度はデータシートに書かれていない。平均電流のログには使えるが、PWM 1周期の変化まで追えるかは実測が必要。ADC の前に軽い RC フィルタを入れる。

## マウスで使うときに便利な点

- **出力電圧を I2C で変えられる**。探索と最短走行で電源電圧を切り替える、走行前に決めた値を設定する、といった使い方ができる。試作機は可変にしておき、実走行で電圧を決めるのがよい。
- **電池が減っても電圧が変わらない**。モータの制御ゲイン・フィードフォワードが電池残量に左右されなくなる。
- **出力電流の制限をハードウェアで掛けられる**（IOUT_LIMIT レジスタ 02h）。ソフトの電流制限と合わせて二重の保護になる。
- **FPWM モードでは出力側から入力側へ電力が流れる**。回生ブレーキで戻ってきた電流を電池側へ逃がせるので、出力電圧の跳ね上がりを抑えられる。PFM モードでは逆流を止めるので、**走行中は FPWM で使う**。

## 2倍に昇圧するときの心配な点

1. **モータの定格に対して約4倍の電圧になる**
   NFP-D0812-1-3.7 は 3.7V 定格。15V では拘束電流が約4倍、発熱が約16倍になる。ソフトで duty の上限（逆起電力を見込んだ電流制限）を掛けないとすぐ焼ける。
   電源電圧が高いことが効くのは**最高速付近だけ**（逆起電力に負けない電圧が要る）。低速域では duty を下げて捨てているだけになる。
2. **モータドライバ MP6551 の耐圧**
   Mk3 では 2S 直結で定格内として使っている。15〜17V（＋回生時の跳ね上がり）に耐えるかは未確認。足りなければ 20V 超のドライバに変える。
3. **PWM のリップルと分解能**
   コアレスモータはインダクタンスが小さいので、電源電圧を上げると電流リップルが増える。PWM 周波数を上げる必要があり、そのぶんドライバの損失が増える。使う duty の幅が狭くなるので、実効的な分解能も下がる。
4. **吸引ファン（MK06-45）は昇圧後の電源につながない**。電池直結のまま、または別系統にする。
5. **コンデンサの耐圧と容量低下**
   15V 系＋回生の跳ね上がりなので、25V 品以上を使う。セラミックコンデンサは電圧を掛けると実容量が減る（DC バイアス特性）ので余裕を持たせる。
6. **インダクタの大きさ**
   飽和電流 10A 以上のものは 5mm 角以上になりがち。ハーフサイズの1枚基板では、場所と高さが厳しい。
7. **ノイズ**
   スイッチングノードを、ジャイロ（LSM6DSRX）・壁センサの受光（LTR-209）・エンコーダ（AS5047P）から離す。スイッチング周波数は、センサのサンプリングと干渉しない値を選ぶ。
8. **3.3V 系は電池から直接取る**
   LXDC55 を昇圧器の後ろにしない。昇圧器が過電流で止まったときに、MCU まで落ちるのを防ぐ。

## モータに流れる電流の考え方

```
I = (V × duty − Ke × ω) / R
```

- 走行中の電流は**電源電圧ではなく、必要なトルクで決まる**（I ≈ トルク ÷ Kt）。15V に上げても、同じ加速度なら電流はほぼ同じ。
- 電源電圧が決めるのは**流れうる最大の電流**。止まっているとき（ω=0）に duty 100% を出すと I = V / R が流れる。
- NFP-D0812 のモータ定数（巻線抵抗 R、逆起電力定数 Ke）はまだ測っていない。仮に R ≈ 3Ω とすると、拘束電流は 3.7V で約1.2A、7.4V で約2.5A、15V で約5A（1モータあたり）。
