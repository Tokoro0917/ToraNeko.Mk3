# hardware/

回路・基板の設計データを格納します。設計ツールは [KiCad](https://www.kicad.org/) を使用します。

## 構成の考え方

基板（プロジェクト）ごとにディレクトリを分けて `hardware/kicad/` 以下に配置してください。例:

```
hardware/
└── kicad/
    ├── main-board/
    ├── motor-driver-board/
    └── sensor-board/
```

各プロジェクトディレクトリには、KiCad のプロジェクト一式（`.kicad_pro` / `.kicad_sch` / `.kicad_pcb` など）に加えて、
以下も一緒に管理することを推奨します。

- `BOM.csv`（部品表）
- `README.md`（基板の役割、電源電圧、コネクタ・ピンアサインの概要）
- 発注用に出力したガーバー・ドリルデータ（`fab-output/` 等のサブディレクトリにまとめる）

## 運用メモ
