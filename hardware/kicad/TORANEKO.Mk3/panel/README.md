# エンコーダ基板パネル

エンコーダ基板（6 × 8.5 × 0.6mm）を 6 枚（IC5 側 ×3、IC7 側 ×3）並べた発注用パネル。メイン基板とは別の注文で出す。

![パネル](panel_preview.png)

| 項目 | 値 |
|---|---|
| パネル寸法 | 60 × 22.5mm（枠 5mm、基板間・枠との隙間 2mm） |
| 基板の固定 | 左右の辺のタブ（上端から 0.5〜2.5mm、幅 2mm）＋ミシン目（NPTH Φ0.5mm、ピッチ 0.75mm、1か所 3 穴） |
| はんだ付けする辺（下辺） | タブなし。ルーターで切るのできれいな辺になる |
| 上辺 | タブなし（AS5047P のパッドまで 0.22mm しかないため） |

- ミシン目の穴は基板の外側（タブ側）に置いてあり、折ったあとの残り（バリ）は基板の外に出る。穴から銅箔までは 0.8mm 以上
- パネル内の各コピーは別のネット名（`_2`, `_3` 付き）にしてあるので、DRC で「未接続」は出ない

## 作り直し方

メイン基板（`../TORANEKO.Mk3.kicad_pcb`）のエンコーダ部分を修正したら、次で作り直す。

```bash
python3 make_encoder_panel.py
```

- 必要なライブラリ: `shapely`
- エンコーダ基板の外形の位置（スクリプト内の `BOARDS`）が変わった場合は、そこも直す

## 発注時の設定（JLCPCB の例）

- Panel by Customer（自分で面付け済み）、V-Cut なし
- 厚さ 0.6mm、2 層
- ガーバーは KiCad でこのファイルを開いて出力する
