# TORANEKO.Mk3

ToraNeko.Mk3 のメイン基板（1枚基板・全機能統合、基板一体型シャーシ）のKiCadプロジェクトです。

KiCadプロジェクト本体（`TORANEKO.Mk3.kicad_pro` / `.kicad_sch` / `.kicad_pcb`）を作成済みです（現状は空、これから回路図を起こしていきます）。
このディレクトリには、実際に回路図を起こす前に固めておいた機能ブロック構成・ペリフェラル割り当て案・BOMドラフトも一緒に置いています。

## 機能ブロック

| ブロック | 内容 |
|---|---|
| MCU | STM32F411CEU6 |
| モータドライバ | MP6551 × 2（左モータ用・右モータ用） |
| モータ | NFP-D0812-1-3.7（ブラシ付きDC）× 2 |
| エンコーダ | AS5047P（磁気式）× 2、左右モータ軸に取り付け |
| IMU | LSM6DSRXTR |
| 壁センサ | 反射型IR。受光: LTR-209、発光: OSI5FU3A11C、LEDドライバ: **NCR321PAS**（定電流・PWM対応）。前方斜め左右2組・側面左右2組の計4組 |
| 吸引ファン | サクションファン × 1（型番未定）。NチャネルMOSFETによるローサイドPWM駆動 |
| 電源 | 2セルLiPo入力 → MCU/センサ用3.3V系（**LXDC55FAAA-203**）、モータドライバ（MP6551）はLiPo直結 |
| デバッグ/書き込み | STLINK-V3MODS（SWD＋仮想COMポート）。USBは使わない |
| クロック | HSE 水晶 10MHz → SYSCLK 100MHz |

## ペリフェラル割り当て案（STM32F411CEU6）

正確なピン番号はKiCadで回路図を起こす際にデータシート（UFQFPN48パッケージ）で確定してください。
ここではどのペリフェラルをどのブロックに割り当てるかの方針のみ示します。

- **SPIバス（IMU・エンコーダ用）**: LSM6DSRXTR、AS5047P × 2 は共通SPIバス上にCS（チップセレクト）を分けて接続する案。SPIバスを分割するかは配線の都合で判断。
- **PWM（モータ駆動用）**: MP6551 × 2 に対し、1モータあたり2本（IN1/IN2、もしくはPWM+DIR）を想定。TIM1などの高機能タイマーを優先的に割り当てる。
- **ADC（壁センサ用）**: LTR-209（受光）× 4組ぶんでADC 4チャンネル（PA3〜PA6）を使用。OSI5FU3A11C（発光）側は **NCR321PAS**（LED 1個につき1個）の VEN を GPIO 2本で2組ずつ駆動する（組A: PB0、組B: PA7）
- **PWM（吸引ファン用）**: MOSFETゲート駆動用に1チャンネル。モータ駆動用タイマーとは別チャンネルを割り当てる。
- **UART（ログ出力）**: USART1（PA9 TX / PA10 RX）を STLINK-V3MODS の仮想COMポートに接続する案。USBは使わないので PA11/PA12 は他用途に使える。
- **SWD**: STLINK-V3MODS での書き込み・デバッグ用に PA13（SWDIO）/ PA14（SWCLK）/ NRST を確保。SWO（PB3）は任意。

## 電源設計メモ

- 入力: 2セルLiPo（7.4V公称、満充電8.4V程度）
- MCU/センサ系: 3.3Vへ降圧、**LXDC55FAAA-203** を使用
- 壁センサLEDドライバ（NCR321PAS）: **3.3V系から給電（決定）**。センサ周りにバッテリ電圧（変動する電圧）を持ち込まないため。LED 1個につき NCR321PAS 1個、**ピーク約 155mA** のパルス点灯。回路は下記「壁センサ発光回路」を参照
- モータ系: LiPoをレギュレータを介さず**MP6551に直結**（MP6551の定格電圧範囲内であることを確認済みとして進める）
- 吸引ファン系: LiPoから供給、MOSFETでPWM制御（レギュレータを挟むかはファン選定後に確定）

## 壁センサ発光回路

LED 1個につき NCR321PAS 1個（×4組）。発光制御の GPIO は2本で、1本の GPIO で2個の VEN を同時に駆動する（組A: PB0 → IC3/D7 と IC8/D9、組B: PA7 → IC4/D8 と IC9/D10）。組み合わせは **組A = 左前向き＋右向き、組B = 右前向き＋左向き**。横向きの2組は光軸が機体中央で交差する（クロス配置）が、別の組なので同時には点かない。同時に点く2組は向きが反対なので干渉しにくい。ただし同じ組の2個は機体の同じ側に並ぶ（右向きは左側に付いて右を向くため）ので、LED からの光が隣の受光素子に直接入らないよう、センサホルダで遮光する。

2個同時点灯なのでピーク電流は約 310mA（155mA × 2）。大容量コンデンサの電圧降下も2倍になり、NCR321PAS の電圧余裕は最悪で 1.4V をわずかに下回る見込み。足りない場合は電流が少し下がる（暗くなる）だけなので、実測で確認する。

```
【電源部：4組で共通】

 +3V3 ──[FB1]──┬──────────┬───────────── 3V3_LED（LED1〜4のアノードへ）
 (MCU系)        │          │
            C1,C2 ═╧═      C3 ═╧═ 0.1µF
         47µF×2 │          │
                 GND        GND

【発光部：1組分（×4組）】

 3V3_LED
    │
    ▼  D1  OSI5FU3A11C（1: アノード、2: カソード）
    │
  ┌─┴──────────────── U1 NCR321PAS ──┐
  │  6: IOUT / 7: IOUT（裏面パッド）  │
  │  1: VEN ◄───────┬──────── GPIO（組A: PB0 / 組B: PA7、1本で2個の VEN を駆動）
  │                R2 100kΩ           │
  │                 │                 │
  │                GND                │
  │  2: REXT ──[R1 5.1Ω 1%]── GND     │
  │  5: GND ───────────────── GND     │
  │  3, 4, 8: N/C                     │
  └───────────────────────────────────┘
```

| 記号 | 部品 | 値 | 数 | 備考 |
|---|---|---|---|---|
| D1 | 赤外LED | OSI5FU3A11C | 4 | 940nm。IF=100mA で VF typ 1.35V / max 1.6V。パルス最大 1000mA（100µs, 1/100） |
| U1 | 定電流ドライバ | NCR321PAS | 4 | DFN2020D-6 |
| R1 | Rext | 5.1Ω 1% | 4 | 約 155mA（データシート Fig.16/17 の 4Ω≒190mA、6Ω≒135mA から 1/Rext で補間）。E96 の 4.99Ω なら約 160mA。センサごとに差し替え可能なよう 0603/0805 |
| R2 | VEN プルダウン | 100kΩ | 4 | リセット中（GPIO 入力状態）に LED が点かないようにする |
| FB1 | フェライトビーズ | 0603、定格 300mA 以上、DCR 0.1Ω 以下 | 1 | 0Ω でも可。MCU・ADC 側の 3.3V にパルス電流を流さないため |
| C1, C2 | バルクコンデンサ | 47µF 10V X5R 1206 | 2 | DC バイアス込みで実効 100µF 程度を確保。ドライバ直近 |
| C3 | デカップリング | 0.1µF | 1 | ドライバ直近。4組が離れる場合は各ドライバに追加 |

### 設計上の注意

- **VEN は GPIO から直結**（直列抵抗を入れない）。EN 電圧で出力電流が変わる（Fig.24）ため。VEN の絶対最大定格は 4.5V
- **NCR321PAS の裏面パッド（7ピン）は IOUT。GND ではない。** GND ベタにつなぐと LED が常時点灯になる。LED カソードと同じネットにし、放熱用に銅箔を確保する
- 電圧余裕（155mA 時の見積り）: 3.3V − C1,C2 電圧降下（約 31mV: 155mA × 20µs / 100µF）− FB1（約 16mV）− VF（推定 typ 1.65V / 最悪 1.8V）= **typ 約 1.6V / 最悪 約 1.45V**。NCR321PAS の最小オーバーヘッド 1.4V を満たす（180mA〔4.3Ω〕だと最悪で約 1.4V とぎりぎりになるため、安定性を優先して 5.1Ω とした）
  - このため **1回の点灯時間は 10〜20µs** を目安にする（ソフト側で調整）
  - 余裕が足りない場合は電流が設定値より下がる（暗くなる）だけで、壊れはしない。ただし明るさが温度で変わりやすくなる
- パルス電流のループ（C1,C2 → LED → U1 → R1 → GND → C1,C2）を小さくし、受光側・ADC 入力の近くを通さない
- 側面センサは壁が近く、受光側が飽和する可能性がある。実測で距離と AD 値の関係を確認し、必要ならセンサごとに Rext を変える（例: 側面は 9.1Ω≒100mA）

## 部品配置ガイド（DXF）

機体全体の STEP（`mechanical/exported/TORANEKO.Mk3_v36.step`）から、配置の目安になる DXF を生成したもの。KiCad の PCB エディタで「ファイル → インポート → グラフィック」から `User.Drawings` などのレイヤーに読み込み、ガイド内の基板外形（レイヤー `00_BOARD`）が既存の Edge.Cuts に重なるように置く。

## エンコーダ接続用フットプリント（`TORANEKO_Encoder.pretty/`）

エンコーダ基板（6 × 8.5 × 0.6mm）をメイン基板に垂直に立て、はんだで接続するためのフットプリント。左右のエンコーダ基板は同じ設計のまま使える（180° 回して置くだけ）。

| フットプリント | 使う部品 | 原点 | パッド |
|---|---|---|---|
| `TN_ENC_Edge` | エンコーダ基板側（U3, U5） | はんだ付けする辺の中央。+Y が基板の奥（メイン基板から離れる向き） | 1〜4（MOSI, MISO, SCK, CS）: 裏面、幅 0.9mm、ピッチ 1.4mm、辺から 0.2〜1.2mm。5〜6（VCC, GND）: チップ面、幅 2.0mm、辺から 0.2〜0.72mm（AS5047P のパッドと 0.2mm 以上離す） |
| `TN_ENC_Base` | メイン基板側（U4, U6） | エンコーダ基板が立つ位置の中央。−Y がチップ側 | 1〜4: 裏面側の列、5〜6: チップ側の列。エンコーダ基板の面（中心から ±0.3mm）から外へ 1.0mm |

- `TN_ENC_Edge` の `Dwgs.User` に、磁石の軸（辺から 4.613mm）と AS5047P の外形（5.0 × 4.4mm）を描いてある。AS5047P はその中心に合わせ、90° 回して置く
- `TN_ENC_Base` の置き方（回転は KiCad の角度）:

| | 位置 | 回転 |
|---|---|---|
| 右エンコーダ（U4 か U6、チップが +X 向き） | (118.557, 66.05) | 270° |
| 左エンコーダ（チップが −X 向き） | (101.243, 66.05) | 90° |

- エンコーダ基板は小さいため、基板端クリアランス（基板のセットアップ → 制約 → 銅箔から基板端）は **0.2mm** にする（0.5mm だと AS5047P のパッドとエッジパッドが違反になる。AS5047P のパッドは上端から 0.22mm）
- ライブラリの追加: 設定 → フットプリントライブラリの管理 → プロジェクト固有のライブラリ に `${KIPRJMOD}/TORANEKO_Encoder.pretty` を追加
